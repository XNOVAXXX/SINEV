# Administrador

Rol de autenticación para el personal administrador de SINEV.

- Rol Supabase: `administrador`
- Puede consultar vehículos.
- No puede editar ni eliminar ningún registro (vehículos, campañas, avisos ni usuarios).
- Puede ejecutar campañas.
- Puede crear usuarios administradores u operadores (Dashboard → Usuarios, mediante la función `crear-usuario`).
